REST API

curl "{{ base_url }}/api/transactions/sample?label=illicit"
curl "{{ base_url }}/api/transactions/TX_ID"
curl -X POST "{{ base_url }}/api/score" \
  -H "Content-Type: application/json" \
  -d @transaction.json

A scoring request is a JSON object with time_step (35 to 49), features (165 numbers in dataset order, or an object keyed local_1 to local_93 and agg_1 to agg_72), and inputs and outputs (ids of existing transactions in that step). The response carries the risk, the flag, the top drivers, the neighbourhood and the server-side latency.
